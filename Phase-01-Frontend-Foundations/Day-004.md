---

## 🔍 3. Line-by-Line Code Breakdown
- `<img>`: Self-closing tag (does NOT need `</img>`).
- `src`: Path or URL of the image file.
- `alt`: Alternate description read by search engines and blind users using screen readers.
- `<figure>` and `<figcaption>`: Semantic container grouping an image with its caption.
