## 💻 2. Complete Working Code
Save this file into your workspace as `day-23/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
const userRole = "admin";
const accountBalance = 500;
const itemCost = 350;

if (accountBalance >= itemCost) {
  console.log("Payment approved! Item purchased.");
} else {
  console.log("Transaction declined: Insufficient funds.");
}

// Concise Ternary Operator: condition ? valueIfTrue : valueIfFalse
const accessMessage = (userRole === "admin") ? "Full Access Granted" : "Restricted Access";
console.log(accessMessage);
```

## 🔍 3. Line-by-Line Code Breakdown
- `===`: Strict equality comparison (checks both value and data type).
- `if / else`: Standard conditional branching.
- Ternary: Single-line shorthand for simple if-else assignment.
