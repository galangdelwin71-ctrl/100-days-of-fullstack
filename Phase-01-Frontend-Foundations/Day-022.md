## 💻 2. Complete Working Code
Save this file into your workspace as `day-22/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
const productPrice = 1200;
const taxRate = 0.12; // 12% VAT
const discount = 150;

const taxAmount = productPrice * taxRate;
const finalTotal = (productPrice + taxAmount) - discount;

// Modern Template Literal using backticks ``
console.log(`Subtotal: ₱${productPrice}`);
console.log(`VAT: ₱${taxAmount}`);
console.log(`Grand Total: ₱${finalTotal}`);
```

## 🔍 3. Line-by-Line Code Breakdown
- Operators: `+` (add), `-` (subtract), `*` (multiply), `/` (divide), `%` (modulo/remainder).
- Template Literals: Enclosed in backticks (`` ` ``); variables embedded via `${variableName}`.
