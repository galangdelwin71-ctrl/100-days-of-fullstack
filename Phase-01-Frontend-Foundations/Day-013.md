## 💻 2. Complete Working Code
Save this file into your workspace as `day-13/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<head>
  <!-- Load Inter font from Google Fonts -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700;900&display=swap" rel="stylesheet">
  <style>
    body {
      font-family: 'Inter', sans-serif;
      line-height: 1.6; /* Comfortable reading spacing */
      font-size: 16px;
    }
    h1 {
      font-size: 2.25rem;
      letter-spacing: -0.05em; /* Sleek tight modern headline */
      font-weight: 900;
    }
  </style>
</head>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<link rel='stylesheet'>`: Imports external web fonts from Google Fonts CDN.
- `font-family`: Defines primary font with fallback system fonts.
- `line-height: 1.6`: Vertical spacing between lines of text for readability.
- `letter-spacing`: Tightens or expands horizontal space between letters.
