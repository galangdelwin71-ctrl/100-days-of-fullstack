## 💻 2. Complete Working Code
Save this file into your workspace as `day-19/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  /* Base styles: Mobile default (1 column) */
  .layout-container {
    display: flex;
    flex-direction: column;
    gap: 16px;
  }
  /* Tablet breakpoint */
  @media (min-width: 768px) {
    .layout-container {
      flex-direction: row;
    }
  }
</style>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- Mobile-First: Write baseline styles for small screens first, then progressively enhance for larger displays.
- `@media (min-width: 768px)`: Applies styles only when viewport width reaches or exceeds 768 pixels (standard iPad / tablet width).
