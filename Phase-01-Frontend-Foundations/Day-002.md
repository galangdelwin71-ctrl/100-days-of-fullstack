## 💻 2. Complete Working Code
Save this file into your workspace as `day-02/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<h1>Main Article Title (h1)</h1>
<h2>Section Topic (h2)</h2>
<h3>Subsection Detail (h3)</h3>
<p>You can make words <strong>bold for importance</strong> or <em>italic for emphasis</em>.</p>
<p>Here is an <mark>highlighted keyword</mark> and a <del>deleted price</del> <ins>₱999 sale price</ins>.</p>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<h1>` to `<h6>`: Establishes clear heading hierarchy (h1 is primary, h6 is smallest).
- `<strong>`: Bold text with semantic importance for SEO and screen readers.
- `<em>`: Emphasized italicized text.
- `<mark>`: Yellow highlight marker.
- `<del>` and `<ins>`: Strikethrough old text and inserted new text.
