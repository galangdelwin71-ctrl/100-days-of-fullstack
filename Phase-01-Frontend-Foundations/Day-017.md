## 💻 2. Complete Working Code
Save this file into your workspace as `day-17/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  .product-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 equal columns */
    gap: 20px;
    padding: 20px;
  }
  .product-card {
    background: #1e293b;
    padding: 24px;
    border-radius: 12px;
    color: white;
  }
</style>
<div class="product-grid">
  <div class="product-card">Product A</div>
  <div class="product-card">Product B</div>
  <div class="product-card">Product C</div>
</div>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `display: grid`: Activates 2D grid formatting context.
- `grid-template-columns: repeat(3, 1fr)`: Defines three equal flexible columns (`1fr` = 1 fraction of free space).
- `gap: 20px`: Sets uniform gutter distance between grid columns and rows.
