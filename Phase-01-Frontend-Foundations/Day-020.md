## 💻 2. Complete Working Code
Save this file into your workspace as `day-20/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  .btn {
    background: #3b82f6;
    color: white;
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    cursor: pointer;
    transition: all 0.25s ease-in-out;
  }
  .btn:hover {
    background: #2563eb;
    transform: translateY(-3px);
    box-shadow: 0 10px 15px -3px rgba(59, 130, 246, 0.4);
  }
</style>
<button class="btn">Elevate Button</button>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `transition: all 0.25s ease-in-out`: Smoothly animates CSS property changes over a quarter of a second.
- `transform: translateY(-3px)`: Lifts element upward.
- `box-shadow`: Adds glowing soft depth.
