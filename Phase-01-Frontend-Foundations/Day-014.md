## 💻 2. Complete Working Code
Save this file into your workspace as `day-14/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  .card {
    position: relative; /* Parent anchor */
    width: 280px;
    padding: 20px;
    background: #1e293b;
    color: white;
    border-radius: 12px;
  }
  .badge {
    position: absolute; /* Placed relative to .card */
    top: 10px;
    right: 10px;
    background: #ef4444;
    padding: 4px 8px;
    border-radius: 4px;
    font-size: 12px;
  }
  .sticky-header {
    position: sticky;
    top: 0;
    background: #0f172a;
    padding: 12px;
    z-index: 100;
  }
</style>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `position: relative`: Acts as coordinate anchor for absolute children without breaking document flow.
- `position: absolute`: Removes element from flow, positioning via top/right/bottom/left relative to nearest positioned ancestor.
- `position: sticky`: Scrolls naturally until hitting specified threshold (e.g. `top: 0`), then sticks to viewport.
