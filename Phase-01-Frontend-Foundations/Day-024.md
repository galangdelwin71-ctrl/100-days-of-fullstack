## 💻 2. Complete Working Code
Save this file into your workspace as `day-24/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
// Modern Arrow Function syntax
const calculateDiscount = (price, percentage) => {
  const discountAmount = price * (percentage / 100);
  return price - discountAmount;
};

const salePrice = calculateDiscount(2000, 20); // 20% off 2000
console.log(`Sale Price: ₱${salePrice}`); // 1600
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `const funcName = (params) => { ... }`: Clean ES6 arrow function standard.
- `return`: Sends computed output value back to caller.
- Parameters: Inputs passed into function definition.
