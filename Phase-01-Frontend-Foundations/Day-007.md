## 💻 2. Complete Working Code
Save this file into your workspace as `day-07/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<form action="/submit" method="POST">
  <div>
    <label for="username">Username:</label>
    <input type="text" id="username" name="username" placeholder="e.g. delwin71" required />
  </div>

  <div>
    <label for="usermail">Email Address:</label>
    <input type="email" id="usermail" name="usermail" placeholder="you@domain.com" required />
  </div>

  <div>
    <label for="bio">Short Biography:</label>
    <textarea id="bio" name="bio" rows="4" cols="30" placeholder="Tell us about yourself..."></textarea>
  </div>

  <button type="submit">Submit Registration</button>
</form>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<form>`: Container handling submission behavior.
- `<label for='id'>`: Binds label text to an input for accessibility.
- `<input type='email'>`: Enforces valid email syntax natively.
- `<textarea>`: Multi-line text field.
- `<button type='submit'>`: Triggers form transmission.
