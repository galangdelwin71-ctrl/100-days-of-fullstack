Connecting pages and navigating external websites using the anchor tag.

## 💻 2. Complete Working Code
Save this file into your workspace as `day-03/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<!-- External Link opening in new tab -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">Search on Google</a>

<!-- Internal Anchor jumping to a section on the same page -->
<a href="#contact-section">Jump to Contact</a>

<div style="margin-top: 500px;" id="contact-section">
  <h2>Contact Details</h2>
  <p>Email: developer@example.com</p>
</div>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<a href='...'>`: Anchor tag where `href` specifies destination URL.
- `target='_blank'`: Forces link to open in a fresh new browser tab.
- `rel='noopener noreferrer'`: Crucial security attribute preventing the new page from accessing window.opener.
- `href='#id'`: In-page jump navigation matching an element's `id` attribute.
