## 💻 2. Complete Working Code
Save this file into your workspace as `day-11/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<!DOCTYPE html>
<html>
<head>
  <style>
    /* Element Selector */
    body {
      background-color: #0f172a;
      color: #f8fafc;
      font-family: Arial, sans-serif;
    }
    /* Class Selector (starts with dot) */
    .highlight-card {
      background-color: #1e293b;
      padding: 16px;
      border-radius: 8px;
    }
    /* ID Selector (starts with hash) */
    #main-title {
      color: #38bdf8;
    }
  </style>
</head>
<body>
  <h1 id="main-title">Modern CSS Styling</h1>
  <div class="highlight-card">
    <p>This text is styled with a dark navy background and cyan accents.</p>
  </div>
</body>
</html>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `body { ... }`: Applies global default styles to entire page.
- `.highlight-card`: Class selector reusable across multiple elements.
- `#main-title`: ID selector strictly targeting one unique element.
- CSS Hex Colors: `#0f172a` is dark navy blue; `#38bdf8` is vibrant cyan.
