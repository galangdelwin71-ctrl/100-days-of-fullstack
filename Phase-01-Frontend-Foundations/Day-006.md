---

## 🔍 3. Line-by-Line Code Breakdown
- `<table>`: Container for tabular information.
- `<thead>` & `<tbody>`: Separates table header labels from data rows.
- `<tr>`: Table Row.
- `<th>`: Table Header cell (bold and centered by default).
- `<td>`: Table Data cell for standard records.
