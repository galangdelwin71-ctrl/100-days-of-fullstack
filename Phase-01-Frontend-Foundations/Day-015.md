## 💻 2. Complete Working Code
Save this file into your workspace as `day-15/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  .navbar {
    display: flex;
    flex-direction: row;
    justifyContent: space-between; /* Logo left, buttons right */
    align-items: center;          /* Vertical center */
    padding: 16px 24px;
    background-color: #1e293b;
  }
</style>
<nav class="navbar">
  <div class="logo" style="color: #38bdf8; font-weight: bold;">MyApp</div>
  <div class="links" style="display: flex; gap: 16px;">
    <a href="#" style="color: white; text-decoration: none;">Features</a>
    <a href="#" style="color: white; text-decoration: none;">Pricing</a>
  </div>
</nav>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `display: flex`: Activates Flexbox context on container.
- `justify-content: space-between`: Pushes first child to left edge and last child to right edge.
- `align-items: center`: Aligns items vertically in the middle.
- `gap: 16px`: Modern standard property spacing flex children apart.
