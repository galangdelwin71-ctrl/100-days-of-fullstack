## 💻 2. Complete Working Code
Save this file into your workspace as `day-12/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  * {
    /* The Golden CSS Reset: Includes padding and border in total width */
    box-sizing: border-box;
    margin: 0;
    padding: 0;
  }
  .box {
    width: 300px;
    background-color: #3b82f6;
    color: white;
    padding: 20px;         /* Space INSIDE the border */
    border: 4px solid #1d4ed8; /* The frame */
    margin: 30px auto;     /* Space OUTSIDE the border (centered) */
  }
</style>
<div class="box">
  Content sits inside padding.
</div>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `box-sizing: border-box;`: Prevents padding and borders from unexpectedly increasing element width.
- `padding`: Space between text content and inner border.
- `border`: The outline edge around padding.
- `margin`: Exterior cushion separating element from neighboring elements.
- `margin: 0 auto;`: Centers a fixed-width block horizontally.
