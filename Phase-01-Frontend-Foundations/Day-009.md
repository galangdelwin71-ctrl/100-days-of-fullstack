## 💻 2. Complete Working Code
Save this file into your workspace as `day-09/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<!DOCTYPE html>
<html lang="en">
<body>
  <header>
    <h1>TechPulse News</h1>
    <nav><a href="#home">Home</a> | <a href="#articles">Articles</a></nav>
  </header>

  <main>
    <article>
      <h2>Why Web Development is Booming in 2026</h2>
      <p>Written by Delwin on September 27, 2026</p>
      <section>
        <h3>Rise of Full-Stack Frameworks</h3>
        <p>Developers who master both frontend and backend are in high demand.</p>
      </section>
    </article>
  </main>

  <footer>
    <p>&copy; 2026 TechPulse. All rights reserved.</p>
  </footer>
</body>
</html>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<header>`: Page or article banner.
- `<nav>`: Navigation links container.
- `<main>`: Unique core body content of the document.
- `<article>`: Self-contained post or card.
- `<section>`: Thematic grouping of content.
- `<footer>`: Closing author or copyright metadata.
