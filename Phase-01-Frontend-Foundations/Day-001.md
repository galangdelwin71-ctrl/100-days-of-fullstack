## 💻 2. Complete Working Code
Save this file into your workspace as `day-01/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Day 1: My First Web Page</title>
</head>
<body>
  <h1>Hello World! I am learning Full-Stack Web Development.</h1>
  <p>Today is Day 1. I am building the foundation of my programming career.</p>
</body>
</html>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `<!DOCTYPE html>`: Tells the browser this document is written in modern HTML5.
- `<html>`: The root wrapper containing the entire webpage.
- `<head>`: Holds behind-the-scenes data like the page title and charset.
- `<body>`: Contains everything visible on screen.
- `<h1>`: Heading 1, the largest and most important page title.
- `<p>`: Paragraph tag for standard text content.
