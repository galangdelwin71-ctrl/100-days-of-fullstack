## 💻 2. Complete Working Code
Save this file into your workspace as `day-08/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<form>
  <!-- Radio Buttons (Single Choice, must share same 'name') -->
  <p>Select Plan:</p>
  <input type="radio" id="free" name="plan" value="free" checked />
  <label for="free">Free Starter</label>
  <input type="radio" id="pro" name="plan" value="pro" />
  <label for="pro">Pro Edition</label>

  <!-- Checkbox (Multiple choices allowed) -->
  <p>Notifications:</p>
  <input type="checkbox" id="newsletter" name="newsletter" />
  <label for="newsletter">Email weekly newsletter</label>

  <!-- Number with limits -->
  <p>Age:</p>
  <input type="number" min="18" max="99" required />
</form>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- Radio buttons: Must share the identical `name` attribute so only one can be checked at a time.
- Checkboxes: Independent toggle options.
- `min` & `max`: Restricts numerical inputs without requiring custom JavaScript.
- `required`: Prevents form submission if field is empty.
