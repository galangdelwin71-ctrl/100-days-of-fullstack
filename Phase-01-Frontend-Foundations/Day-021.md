---

## 🔍 3. Line-by-Line Code Breakdown
- `const`: Declares a read-only constant reference. Always use `const` by default.
- `let`: Used only when variable value must change over time.
- `console.log()`: Prints output directly to browser Developer Tools console.
- Data types: String, Number, Boolean, Null, Undefined.
