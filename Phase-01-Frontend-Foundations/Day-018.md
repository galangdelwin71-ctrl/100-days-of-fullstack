## 💻 2. Complete Working Code
Save this file into your workspace as `day-18/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
<style>
  /* Fluid responsive grid without media queries! */
  .auto-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 16px;
  }
  .card { background: #334155; color: white; padding: 20px; border-radius: 8px; }
</style>
<div class="auto-grid">
  <div class="card">Item 1</div>
  <div class="card">Item 2</div>
  <div class="card">Item 3</div>
  <div class="card">Item 4</div>
</div>
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `repeat(auto-fit, minmax(250px, 1fr))`: Automatically fits as many 250px cards as possible; cards expand to fill remaining space on wider screens and stack automatically on mobile viewports!
