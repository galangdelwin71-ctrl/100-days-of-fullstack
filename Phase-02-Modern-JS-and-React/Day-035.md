## 💻 2. Complete Working Code
Save this file into your workspace as `day-35/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
async function fetchUserData() {
  try {
    console.log('Fetching...');
    // Simulated delay
    const data = await Promise.resolve({ id: 1, name: 'Delwin' });
    console.log('Loaded:', data.name);
  } catch (err) {
    console.error('Error:', err);
  }
}
fetchUserData();
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `async`: Declares function returns a promise.
- `await`: Pauses execution until promise finishes.
- `try/catch`: Gracefully catches errors.
