## 💻 2. Complete Working Code
Save this file into your workspace as `day-41/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
import { useState } from 'react';
export default function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `useState`: React hook declaring a state variable and setter function.
- When state updates via `setCount`, React re-renders the component instantly.
