## 💻 2. Complete Working Code
Save this file into your workspace as `day-36/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
async function loadQuotes() {
  const response = await fetch('https://api.quotable.io/random');
  const data = await response.json();
  console.log(`"${data.content}" — ${data.author}`);
}
loadQuotes();
```

## 🔍 3. Line-by-Line Code Breakdown
- `fetch(url)`: Native browser method making HTTP network calls.
- `response.json()`: Parses incoming JSON payload into a JavaScript object.
