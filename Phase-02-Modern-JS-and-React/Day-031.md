```javascript
button.addEventListener('click', () => {
  alert('Button clicked!');
});
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `document.querySelector()` finds an element via CSS selector.
- `addEventListener('click', callback)` runs code when the user interacts.
