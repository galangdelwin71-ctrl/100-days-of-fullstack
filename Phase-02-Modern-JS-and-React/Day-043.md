## 💻 2. Complete Working Code
Save this file into your workspace as `day-43/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
export default function ItemList({ items, isLoggedIn }) {
  return (
    <div>
      {isLoggedIn ? <p>Welcome Member</p> : <p>Please Log In</p>}
      <ul>
        {items.map(item => <li key={item.id}>{item.title}</li>)}
      </ul>
    </div>
  );
}
```

## 🔍 3. Line-by-Line Code Breakdown
- Ternary `{condition ? A : B}` renders elements conditionally.
- Always provide unique `key` prop when mapping arrays in React.
