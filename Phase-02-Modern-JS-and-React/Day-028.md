## 💻 2. Complete Working Code
Save this file into your workspace as `day-28/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
const products = [
  { name: 'Mouse', inStock: true },
  { name: 'Keyboard', inStock: false },
  { name: 'Monitor', inStock: true }
];
const available = products.filter(item => item.inStock);
console.log(available);
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `.filter()`: Returns all items satisfying the boolean test condition.
- `.find()`: Returns only the single first matching item.
