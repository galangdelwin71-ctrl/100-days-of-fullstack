## 💻 2. Complete Working Code
Save this file into your workspace as `day-44/index.html` (or `.js` / `.sql` depending on the phase):

```javascript
import { useState, useEffect } from 'react';
export default function PostViewer() {
  const [post, setPost] = useState(null);
  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/posts/1')
      .then(res => res.json())
      .then(data => setPost(data));
  }, []); // Empty array = run once on mount
  return <div>{post ? post.title : 'Loading...'}</div>;
}
```

---

## 🔍 3. Line-by-Line Code Breakdown
- `useEffect(fn, [])`: Runs once after initial render. Perfect for API calls and subscriptions.
